### Описание разделов

1. **Python — Основные навыки**: 36 практических задач на базовый синтаксис, списки, множества, словари, строки, работу с файлами, исключения, модули и библиотеку PIL.
2. **NumPy**: 29 задач по матричным вычислениям, манипуляциям с осями, сортировке, срезам, агрегациям и векторизованным операциям.
3. **Pandas (Titanic)**: 15 комплексных аналитических задач по разведочному анализу данных (EDA), предобработке пропусков, группировке, созданию признаков, сводным таблицам и визуализации выживаемости пассажиров.
4. **Pandas (Video Game Sales)**: 15 аналитических задач по исследованию глобальных и региональных продаж, платформ, жанров, корреляционному анализу и регрессионным зависимостям.
